二、三档测量量程从采样电阻电压差，到ADC采集，最终转换得到三档电流的大小值工作过程完整分析：

（1）由原理图main可以得知，由R0=5mΩ，R1=500mΩ，R2=50Ω
R0两端电压差是Vsense1（左），Vsense2（右）
R1两端电压差是Vsense2（左），Vsense3（右）

由原理图sense可知，使用了INA190A精密电流检测放大器，其目的就是为了
将采样电阻两端的电压差值进行放大，该芯片是A2型号，固定增益是50V/V，支持双向电流检测。

SENSx ───────►│ IN+  
SENSy ───────►│ IN-

所以VOUT=1.5V+50Vshunt

这也就是为什么在空载状态，ADC值：LOW,MID,HIGH都是显示2048的原因

三。从采样电阻两端的电压差值转换，在LCD显示电压，电流值的完整过程分析

1.先补充说明在ADC采集中，最低有效位LSB和ADC量化区间的大小

（1）首先，STM32F411采用了12ADC，但依然是用16位宽度的数据存储变量，所以外设配置要右对齐的原因。
进入正题，LSB可在ADC中可以简单理解为：ADC结果变化1个码，代表输入电压至少变化了多少。

因为2¹² = 4096 ，有4096个量化区间。以ADC参考电压3.0V为例子：
1 LSB = 3.0V ÷ 4096
      = 0.0007324V
      = 0.7324mV
（注意此电压值是经过1/11的电阻网络分压后的）
（未经过分压前，电压颗粒度应为0.7324*11=8.056mv）

可以把0～3V想象成一把尺子：
0V                                              3.0V
│------------------------------------------------│
     总共划分成4096个小格

每个小格宽度：
3.0V ÷ 4096 = 0.7324mV


所以如果ADC值➕1，即电压增加了0.7324mv，比如ADC= 2048，2048*0.7324mv=1.5V


一句话：LSB就是ADC这把尺子的最小刻度。参考电压越低、ADC位数越高，尺子的刻度就越细。


2.电压转换运算过程
(注意：这里求的电压是输入电压，也就是你输入5V给IN端，最终显示在LCD也是要得到5V）
由前面可知，我们求输入电压不是是从采样电阻的电压差入手的！！，而是从R33,R34分压
网络的分压点VADC电压值入手，将其转换为ADC值，最后恢复到VBUS电压。


（1）根据分压公式：VADC = VBUS × R34 ÷ (R33 + R34)
可得VBUS = VADC × 11。所以有
#define VBUS_DIVIDER_GAIN  11.0f		//电阻分压比

（2）从ADC转换为VADC电压：
最小码值 = 0
最大码值 = 4095
VADC = ADC原始值 ÷ 4095 × 3.0V
(float)vol_raw* ADC_VREF_V/ ADC_MAX_CODE


（3）再恢复到VBUS，因为前面硬件已经把VBUS缩小了11倍，所以软件再乘回来：
VBUS = vol_raw × 3.0V ÷ 4095 × 11


例如：
VADC = 1 × 3.0 ÷ 4095
     = 0.000733V
     = 0.733mV

VBUS = 0.000733 × 11
     = 0.00806V


3.电流换算过程
简单来说，就是先从采样电阻的电压差入手，转为ADC值，再转为VADC电压值，最后欧姆定律
（其中采样电阻把电流变成微小压差。INA190把微小压差放大50倍，并叠加1.5V零点。）

完整信号流程：
被测电流 I
    │
    ▼
采样电阻产生压差
VSHUNT = I × R
    │
    ▼
INA190A2放大50倍
    │
    ├── 加上1.5V参考零点
    ▼
VOUT = 1.5V + 50 × VSHUNT
    │
    ▼
STM32 ADC得到 current_raw



（1）首先代码是delta_raw = (int32_t)current_raw -(int32_t)ref_raw;

由于1.5v是叠加用于区分电流方向的，通过压降值是正负可以实现判断方向
所以必须要转换为有符号的整数，比如说
current_raw = 2043
ref_raw     = 2048，那么2043 - 2048 = -5，可知电流是从OUT到IN的


（2）由于根据不同量程使用的采样电阻值大小不一样，通过swich选择电阻值


（3）将由（1）得出的ADC值，转换为INA190输出端的电压差
也就是VOUT差值 = delta_raw × (3.0V ÷ 4096)
这里的3.0v也就是VREF,根据前面分析的ADC中的LSB颗粒度可知，这里是
将ADC的变化值，转换为电压的变化值，也就是电压差

即代码    /* ADC码差换算成INA190输出端的电压差。 */
    ina_output_delta_v =
        (float)delta_raw
        * (ADC_VREF_V / ADC_CODE_COUNT);

以下为例子：假设delta_raw = 5，那么有5 × 0.7324mV= 3.662mV

以上为第一步


第二步是去除INA190的50倍增益，比如3.662mV放大了50倍的
即有代码，    /* 去掉INA190的50倍放大。 */
    shunt_voltage_v =
        ina_output_delta_v / INA190_GAIN;

第三步欧姆定律：
即有代码，    /* 根据欧姆定律I=U/R，计算电流，单位A。 */
    current_a =
        shunt_voltage_v / shunt_resistance;
    /* A转换成µA。 */
    return current_a * 1000000.0f;






4.STEP5 自动量程切档策略说明
===========================

一、档位与切换方向

LOW  = 小电流量程，高灵敏度  
MID  = 中电流量程  
HIGH = 大电流量程，低灵敏度

电流增大：LOW → MID → HIGH，属于升档。  
电流减小：HIGH → MID → LOW，属于降档。


二、为什么升档快、降档慢

升档采用较少确认次数，例如连续 4 点。

原因：电流突然增大时，当前量程可能接近 ADC 饱和，因此要尽快切换到更大量程。

降档采用较多确认次数，例如连续 10 点。

原因：电流变小时，当前大档仍然可以正常测量，只是灵敏度较低，因此可以多观察几个采样点，确认电流确实降低后再切档，避免噪声或瞬态变化导致频繁换挡。

10 kHz ADC 采样下：

4 点 ≈ 0.4 ms  
10 点 ≈ 1.0 ms

所以实际两种切换都很快，只是策略上：

升档：优先防止超量程。  
降档：优先保证稳定。


三、STEP5 状态含义

HOLD：
保持当前档位，没有满足切档条件。

UP_WAIT：
达到升档阈值，正在连续确认，例如 U2/4。

DOWN_WAIT：
达到降档阈值，正在连续确认，例如 D6/10。

SWITCH：
确认完成，本次真正执行档位切换。

SKIP：
切档后的下一整个 ADC 数据块作废，避免模拟开关、运放等切换瞬态产生的脏数据影响判断。

COOL：
切档后的冷却期。ADC 数据可以继续使用，但暂时禁止再次换挡，防止档位来回抖动。


四、整体流程

正常情况：

HOLD
 → UP_WAIT / DOWN_WAIT
 → SWITCH
 → SKIP
 → COOL
 → HOLD

STEP5 的自动量程核心机制就是：

回差阈值
+ 连续确认防抖
+ 切档后丢弃瞬态数据
+ 切档冷却
= 稳定的三档自动量程切换。

核心原则：

“大电流来了快速扩大测量范围，小电流稳定后再谨慎切回高灵敏度量程。”

STEP5 只验证自动换挡机制；绝对精度、零点和校准问题留到后续校准阶段处理。
